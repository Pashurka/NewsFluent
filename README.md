# NewsFluent
**NewsFluent** — кросплатформний мобільний новинний застосунок, розроблений із використанням .NET MAUI та Firebase. Застосунок призначений для персоналізованого перегляду новин, взаємодії з контентом і налаштування користувацького досвіду відповідно до індивідуальних потреб.

## Мета проєкту
Метою розробки є створення зручного та багатофункціонального новинного застосунку, який забезпечує персоналізований доступ до новин, підтримує взаємодію користувачів із контентом і надає можливості налаштування мовних параметрів та зовнішнього вигляду.

## Основні можливості
- Авторизація користувачів.
- Перегляд новин.
- Персоналізація новинної стрічки.
- Створення та перегляд коментарів.
- Підписка на теми новин.
- Автоматичний переклад новин.
- Налаштування мови та зовнішнього вигляду інтерфейсу.
- Розмежування функціональних можливостей відповідно до ролей користувачів.

## Технології
| Технологія | Призначення |
|---|---|
| C# | Основна мова програмування |
| .NET MAUI | Кросплатформна розробка застосунку |
| XAML | Опис інтерфейсу користувача |
| MVVM | Організація взаємодії між інтерфейсом і логікою |
| Firebase | Хмарні сервіси та робота з даними |
| Firebase Firestore | Зберігання даних застосунку |
| REST API | Взаємодія з сервісами авторизації та даними |

## Архітектура
Під час розробки застосовано патерн **MVVM (Model–View–ViewModel)**, який забезпечує розділення інтерфейсу користувача та логіки застосунку.
Для роботи з даними використовується Firebase Firestore. Взаємодія із сервісами авторизації та зберігання даних організована за допомогою REST API.

## Ролі користувачів
Застосунок передбачає підтримку різних категорій користувачів:
- **Гість** — доступ до передбачених для неавторизованого користувача можливостей перегляду.
- **Користувач** — персоналізація новин, коментування та підписка на теми.
- **Адміністратор** — виконання адміністративних функцій.
Доступні операції визначаються роллю користувача.

## Тестування
Проведено функціональне тестування застосунку на Android та UWP-платформах.
Перевірялися авторизація, перегляд новин, коментування, підписки, зміна налаштувань і збереження параметрів після перезапуску. Також оцінювалися коректність відображення інтерфейсу, навігація, масштабування, прокручування та взаємодія із сенсорним і мишиним введенням.
Результати тестування підтвердили працездатність основних функцій у перевірених середовищах.

## Запуск проєкту
Для відкриття та запуску NewsFluent необхідні:
- Visual Studio з підтримкою .NET MAUI;
- відповідний .NET SDK;
- налаштовані компоненти для цільової платформи;
- конфігурація Firebase для доступу до сервісів застосунку.

Клонуйте репозиторій:
```bash
git clone https://github.com/Pashurka/NewsFluent.git
```

Відкрийте solution-файл у Visual Studio, відновіть NuGet-пакети та налаштуйте Firebase відповідно до конфігурації проєкту.
